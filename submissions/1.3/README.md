## 本次改动

**新功能**
- **摇一摇录入**：同一段 A-B 循环重复 3 遍后，底部出现「Shake to add this line」，并预览识别出的句子。摇一摇或点「Add」，这句话就加入当前视频的单词表。
  - 语音识别使用 Apple 设备端模型（iOS 26 的 SpeechAnalyzer），完全不联网
  - 设备不支持时（iOS 26 以下，或没有设备端模型）这个功能自动隐藏
  - 句子长度以 A-B 区间为准，不按词数切。去掉被 A、B 切了一半的词和填充词（えーと、um），以及逗号隔开的句首或句尾称呼（「田中さん、」「, Sarah」）
- **音频语言按播放列表选择**：去掉了「自动」，默认是「未选择」。摇一摇录入需要先选音频语言；释义功能不选也能用。

**改进**
- 长单词、长释义自动折行，完整显示
- 改了单词后点 Done，释义会重新翻译（改回原词则不重翻；升级前的数据不会被批量重翻）
- 回车键显示为「完成」，按下等于点 Done

**修复**
- 按「快进 3 秒」跳过 B 点也算一次循环的问题（现在只统计真正播放过的循环）

## 一、提交前必须完成（按顺序）

### 1. 真机验证 ⚠️ 最重要

语音识别**还没在真机上跑过**（开发用的 Mac 是 Intel 芯片，模拟器无法运行 Apple 的语音模型）。
审核员会照着审核备注测这个功能，所以**这一步不通过就不要提交**，把现象告诉我。

在 Xcode 里把 `feature/loop-capture` 分支直接运行到你的 iPhone 16 上：

| # | 操作 | 预期 |
|---|---|---|
| 1 | 打开一个日语视频的播放列表 →「Languages」→ 音频语言选「日本語」 | 打勾 |
| 2 | 设 A、B，圈住一句台词，让它循环 3 遍 | 底部出现「Shake to add this line」，下面是识别出的句子 |
| 3 | 看预览里的句子 | **有没有标点（。、）**、识别准不准 |
| 4 | 摇一摇手机 | 轻震一下，显示「Added to your words」，单词表末尾多了这句 |
| 5 | 换一段再试，这次点「Add」 | 同上 |
| 6 | 首次使用 | 留意有没有弹出下载语音模型或语音识别权限的提示 |
| 7 | Xcode 底部控制台 | 能看到 `Transcribing with SpeechTranscriber` |
| 8 | 改一个已有释义的单词 → 点 Done | 释义变成新单词的意思 |
| 9 | 加一条很长的句子 | 单词和释义都完整折行显示 |
| 10 | 回归：A-B 循环、倍速、锁屏播放、单词表入口 | 和 1.2 一样正常 |

## 四、审核可能会问的

| 问题 | 回答要点 |
|---|---|
| 为什么要语音识别权限？ | 只把用户循环的那一段转成文字，加入单词表；在设备上完成，不上传 |
| 审核设备上看不到摇一摇的提示 | iOS 26 以下或设备不支持设备端语音模型时，这个功能会隐藏（审核备注里已写明） |
| 是否收集了音频？ | 没有。音频只在设备上识别，App 本身不发起任何网络请求 |
