# 每日精读打卡

目标：量化每天的精读量。英语、日语各自每天推进 15 分钟视频内容，就算当天完成。

只做本地版：数据存本机，不同步，不提醒，不补卡，目标时长固定。

## 计算规则

| 项目 | 规则 |
| --- | --- |
| 精读片段 | 同一段 A-B 完整循环满 **3 遍**（与"添加文字"提示的 `loopsBeforeOffer` 共用同一个数）。完整 = 真的从 A 播到 B，用 +3s 跳过 B 不算。改动 A 或 B 就是新的一段，重新计数 |
| 记多少 | 片段的**视频时长** B − A，与播放速度无关 |
| 同一天重叠 | 当天所有片段按视频取并集，重叠部分只算一次 |
| 跨天 | 每天单独算，昨天学过的片段今天再学照样计入 |
| 片段间空隙 | 不补 |
| 有效时段 | 第 3 遍在 **5:00–23:00** 之间完成才计入，其余时间不计 |
| 锁屏 / 后台 | 算（只要循环还在播） |
| 语言 | 视频所在播放列表的音频语言（`TranslationScope.forVideo(...).audioLanguage`），只统计英语和日语。不在播放列表里或没设语言的不计。语言在记录时写下，之后改设置不影响已记录的数据 |
| 完成 | 某种语言当天合计 ≥ 15 分钟 |

## 单词

- `WordEntry` 新增可选的 `createdAt`，新加的单词写入当时的时间。
- 以前的单词没有日期，不计入任何一天。
- 单词的语言同样按视频所在播放列表的音频语言算。

## 数据

每完成一个精读片段，追加一条记录：

```
date(yyyy-MM-dd, 本地时区) · videoID · language · start · end
```

当天的分钟数 = 按视频分组 → 区间并集 → 求和。只存在本机（UserDefaults 或 JSON 文件）。

## 界面

### 首页
- 去掉"Select Video"大按钮。右上角是 **单词本** 和 **`+`** 两个按钮，`+` 弹出菜单：从相册添加视频 / 新建播放列表。
- 还没有视频时，页面中间显示提示和"添加视频"按钮。
- 从上到下依次是：
  1. **Today 卡片**：今天的半圆、English x/15 min、日本語 x/15 min，下面一排本周 7 天的小圆。点卡片进入月历。
  2. **Continue**：上次播放的视频和停下的位置，点一下继续播。
  3. **Recent**、**Playlists**（与现在相同）。

### 月历
- 每天一个圆：**上半边英语，下半边日语**。完成的一半上色（英语深蓝、日语近黑；深色模式下换成亮一些的颜色），未完成的一半浅灰。
- 已经过去、两种语言都没完成的日子显示 **×**。只完成一种的保持半色。
- 今天：外加一圈强调色描边，下面小字显示两种语言各几分钟（例如 `15·8m`）。
- 还没到的日子是虚线圆，开始用这个功能之前的日子显示空白。左右箭头翻月。
- 底部显示"本月 N 天至少完成一种语言"。

### 日详情（从下方弹出的半屏面板）
- English x min（完成打勾）、日本語 x min、新单词 N 个。
- 最下面一行小字说明计算规则。

### 其他
- 播放列表页的"Add Videos"按钮改成右上角的 `+`，和首页一致。
- 播放器页面不变。
