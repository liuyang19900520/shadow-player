# ShadowPlayer

一个极简的 iOS 视频播放器，专为「A-B 重复播放」（影子跟读 / 反复练习）设计。

## 功能

- **手动选择视频**：从相册挑选视频播放，免相册权限（只访问所选文件）
- **最近播放**：持久化列表，播过的自动置顶
- **A-B 循环**：
  - 🅰 设起点、🅱 设终点，播到 B 自动跳回 A，无限循环
  - ⓒ 取消循环，继续正常播放
- **播放控制**：播放/暂停、进度条拖动
- **快进/快退**：短按跳 3 秒，长按连续扫描（约 5 倍速），松手停止
- 播放时侧边静音拨片打开也能出声

## 技术栈

- SwiftUI + AVPlayer + PHPickerViewController
- iOS 16.0+

## 运行

用 Xcode 打开 `ShadowPlayer.xcodeproj`，在 **Signing & Capabilities** 里选自己的 Team，连真机运行。
